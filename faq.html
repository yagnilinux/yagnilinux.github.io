“Whereof one cannot speak, thereof one must be silent.”

is yagni for me?

probably not. try it in qemu anyway, nothing bad happens there.

why is everything static?

because shared libraries were a mistake.

where is /lib?

there is nothing to put in it.

why is /usr a symlink?

/usr exists because a pdp-11 disk filled up in 1971. ours didn't. the symlink is for scripts that still believe in it.

what does LD_PRELOAD do?

nothing. there is no loader to read it.

will my downloaded binary run?

if it's static.

where's the bootloader?

you don't need one.

what replaces the usual parts?

systemd: busybox init and one script.
udev: mdev.
sudo: doas.
NetworkManager: one wifi file.
dbus: nothing.
shared libraries: nothing.
ld.so: nothing.

why is there bsd and apple code in it?

because it is good code and it isn't gnu.

why is so little packaged?

because you haven't packaged it yet.

do you hate gnu?

yes. here's why.

is it self-hosting?

it could be. the kernel needs gnu make, and we refuse to ship gnu. packages get built on another machine. tcc is for your code.

are packages signed?

no. we're still working on trusting ourselves.

does it run firefox?

not until you port it. netsurf works today.

what hardware works?

x86-64 with uefi. beyond qemu, whatever you've tested.

does it have an installer?

yes. yagni's calamares installer is here.

why yagni?

you aren't gonna need it. if nobody needs it yet, it doesn't go in.

why yagni/linux?

linux is only the kernel. what you're referring to as linux is, in fact, yagni/linux. we're just being pedantic, like richard.

license?

cddl 1.1. the fsf says it's gpl-incompatible. good.
