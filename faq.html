WHO IS IT FOR?

people who want to know how every part of their system works. it has only been tested in qemu.

WHY IS EVERYTHING STATIC?

an upgrade of one package can't break another, and programs start faster without a loader.

WILL A BINARY I DOWNLOADED RUN?

only if it is statically linked.

WHY IS /USR A SYMLINK?

for scripts that start with #!/usr/bin/env.

WHERE IS THE BOOTLOADER?

there is none. the kernel is an efi program, and the firmware runs it directly.

WHAT REPLACES WHAT?

systemd -> busybox init and rcS

udev -> mdev

sudo -> doas

NetworkManager -> wpa_supplicant and udhcpc, started by rcS

dbus, ld.so -> nothing

WHY IS THERE NO GNU SOFTWARE?

see lix.

WHY NOT DÉRIVE?

dérive is good, and requiem learned a lot from it. but dérive is almost 100% gnu free. requiem is 100%.

but mostly:

“Do you really want to live in a world without Coca-Cola?” — Walter White

WHY IS SO LITTLE PACKAGED?

packages are added when someone needs them. see writing packages.

X11 OR WAYLAND?

wayland. xorg could not be linked statically.

IS IT SELF-HOSTING?

no. the kernel's build system needs gnu make, which requiem does not ship. packages are built on another linux machine.

ARE PACKAGES SIGNED?

no. downloads are checked against sha256 sums in the index. the index itself is not signed.

DOES IT RUN FIREFOX?

no. firefox needs glibc and gtk. netsurf is packaged.

WHAT HARDWARE WORKS?

x86-64 machines that boot with uefi. it has only been tested in qemu.

WHAT LICENSE IS IT UNDER?

cddl 1.1. packages keep their own licenses.
