not answered here? read the missal. still not answered? ask.

WHO IS IT FOR?

people who read the source before the readme. try it in qemu first, that's the only place it has ever booted.

WHY STATIC?

so updating one library can't break forty programs. also ldd has nothing to say.

WILL MY DOWNLOADED BINARY RUN?

if it's static. if it wants glibc, it can go back where it came from.

WHY IS /USR A SYMLINK?

so #!/usr/bin/env keeps working. that's the only job it has.

WHERE'S THE BOOTLOADER?

the kernel boots itself. grub was asked to leave.

WHAT REPLACES WHAT?

systemd -> busybox init

udev -> mdev

sudo -> doas

NetworkManager -> one file

dbus, ld.so -> nothing. nobody noticed

WHY NO GNU?

read the sign on the door.

WHY NOT DÉRIVE?

dérive is good, and requiem learned a lot from it. but dérive is almost 100% gnu free. requiem is 100%. it ships built packages, so a base install takes seconds, apps live in ~/apps, the boot is 32 lines, and there is no bootloader.

but mostly:

“Do you really want to live in a world without Coca-Cola?” — Walter White

WILL X BE ADDED TO BASE?

no. base is mine.

WHY SO FEW PACKAGES?

you haven't sent yours yet. here's how.

X11 OR WAYLAND?

wayland. xorg was the one package that wouldn't link static, so it left.

IS IT SELF-HOSTING?

not yet. the kernel still wants gnu make, and we're not happy about it either.

ARE PACKAGES SIGNED?

no. sha256 sums, in an index that isn't signed either. we know.

FIREFOX?

firefox is bigger than requiem. netsurf works.

WHAT HARDWARE WORKS?

x86-64 with uefi. tell us how your thinkpad took it.

WHAT FONT DOES THE WEBSITE USE?

whatever your browser calls verdana.

LICENSE?

cddl 1.1, the license sun wrote for solaris. packages keep theirs. the fsf says it's gpl-incompatible. we consider that a feature.
