answers

“Whereof one cannot speak, thereof one must be silent.” — Ludwig Wittgenstein

If your question is not answered here, it may be answered in the manifesto. If not, ask on the issue tracker.

Who is blackout for?

Anyone who wants to own their system instead of renting it. Every program is static and built without GNU. s6 keeps the services alive. rag builds your bottles from source with the fuel you pick, or hands you prebuilt ones. Apps are folders. The boot is one shell script, the package manager is another, and the compositor is one C file. You can read all of it, and you are expected to.

Why is everything static?

A statically linked program does not depend on other files at runtime, so upgrading one package cannot break another.

Will a binary I downloaded run?

Only if it is statically linked.

Why is /usr a symlink?

For scripts that start with #!/usr/bin/env.

Where is the bootloader?

There is none. The kernel is an EFI program, and the firmware runs it directly. See spark.

What does blackout use instead of the usual parts?

systemds6, s6-linux-init and spark
udevmdev
sudodoas
NetworkManagerwpa_supplicant and udhcpc, supervised by s6
make, ninja, mesonpdpmake, samurai, muon
man-dbmandoc
dbus, ld.sonothing

Why is there no GNU software?

See lix.

Why not dérive?

dérive is good, and blackout learned a lot from it. But dérive is almost 100% GNU free, and blackout is 100%.

“Do you really want to live in a world without Coca-Cola?” — Walter White

Why is so little packaged?

Because you haven't packaged it yet.

X11 or Wayland?

Wayland. Xorg could not be linked statically.

Is blackout self-hosting?

No. The kernel and a few bottles need GNU make, which blackout does not ship, and there is no compiler package yet. Packages are built on another Linux machine.

Are packages signed?

No. Downloads are checked against the sha256 sums in the index, but the index itself is not signed.

Does Firefox run?

No. Firefox needs glibc and GTK. netsurf is packaged.

What hardware works?

x86-64 machines that boot with UEFI. It has only been tested in QEMU.

What license is blackout under?

The CDDL 1.1. The software it packages keeps its own license.
