answers

“Whereof one cannot speak, thereof one must be silent.” — Ludwig Wittgenstein

If your question is not answered here, it may be answered in the missal. If not, ask on the issue tracker.

Who is requiem for?

For people who want to understand every part of the system they run. It has only been tested in QEMU, so that is the place to try it first.

Why is everything static?

A statically linked program does not depend on other files at runtime, so upgrading one package cannot break another.

Will a binary I downloaded run?

Only if it is statically linked.

Why is /usr a symlink?

For scripts that start with #!/usr/bin/env.

Where is the bootloader?

There is none. The kernel is an EFI program, and the firmware runs it directly. See libera.

What does requiem use instead of the usual parts?

systemdbusybox init and libera
udevmdev
sudodoas
NetworkManagerwpa_supplicant and udhcpc, started by libera
dbus, ld.sonothing

Why is there no GNU software?

See lix.

Why not dérive?

dérive is good, and requiem learned a lot from it. But dérive is almost 100% GNU free, and requiem is 100%.

But mostly:

“Do you really want to live in a world without Coca-Cola?” — Walter White

Why is so little packaged?

Because you haven't packaged it yet.

X11 or Wayland?

Wayland. Xorg could not be linked statically.

Is requiem self-hosting?

No. The kernel's build system needs GNU make, which requiem does not ship, so packages are built on another Linux machine.

Are packages signed?

No. Downloads are checked against the sha256 sums in the index, but the index itself is not signed.

Does Firefox run?

No. Firefox needs glibc and GTK. netsurf is packaged.

What hardware works?

x86-64 machines that boot with UEFI. It has only been tested in QEMU.

What license is requiem under?

The CDDL 1.1. The software it packages keeps its own license.
