this is requiem, an experimental x86-64 linux distribution based on musl libc and busybox. it runs great in qemu. on real hardware, you're the beta tester.

requirements:

  • an x86-64 machine that boots with uefi, secure boot off. or qemu.
  • a usb stick.
  • a fair bit of linux knowledge.

features:

  • everything statically linked. no dynamic loader, no /lib.
  • built with clang, lld and compiler-rt. 100% gnu free, unlike a certain os.
  • no /usr or /sbin. (the layout)
  • apps are folders. drag one out of ~/apps and it's uninstalled. (apps)
  • introit package manager, 43 packages.
  • kyrie, a wayland compositor on swc.
  • the kernel boots itself. no bootloader, no initramfs. (efistub)
  • busybox init and a 32 line boot script.

ready-to-boot images:

  • requiem.iso, 37MB, boots to a root shell with everything the install needs
  • requiem.tar.gz, 7MB, the base system as a tarball

build your own from source:

  • https://codeberg.org/requiem-linux/repo
