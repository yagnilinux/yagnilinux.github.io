“The captive is the one whose desires hold him captive.”

yagni/linux is a static x86-64 linux distribution using musl libc and busybox. it runs on x86-64 with uefi and nothing else.

features

  • no dynamic loader
  • no /lib, no /sbin
  • efistub boot
  • jits, a 165 line package manager
  • lzfse compressed packages
  • 1000% gnu free
