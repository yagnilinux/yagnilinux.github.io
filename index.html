“The captive is the one whose desires hold him captive.” — Ibn Taymiyyah

requiem is an opinionated, static x86-64 linux distribution using musl libc and busybox.

features

  • no dynamic loader
  • 3 second base install
  • a unique, opinionated file system
  • efistub boot
  • 32 line boot
  • introit, a 165 line pkg manager
  • 100% gnu free
