yagni/linux is a small, static linux distribution for x86-64 uefi machines, built on musl libc and busybox. it runs great in qemu. on real hardware, you're the beta tester.

features

  • 14MB base, 7MB download
  • <12MB ram idle
  • an upgrade never breaks another program
  • jits, a <180 line package manager
  • luwm, a <180 line window manager on swc
  • 100% gnu free
  • package something in a few minutes

current release: yagni 0.1 WORKS IN QEMU

minimal, not old

yagni isn't small because it runs old software that was light on old computers. it's built on software that is small now: musl libc, busybox and wayland.

is yagni for you?

probably not. read the expectations first. if that page sounds like a chore, it isn't for you.

contribute

package what's missing and send it back. pull requests on github. read what i expect from you first.

why yagni

you aren't gonna need it. if it isn't needed today, it doesn't go in. the rest is spooks.
