“The captive is the one whose desires hold him captive.”

yagni/linux is a small, minimal, statically linked x86-64 linux distribution using musl libc and busybox. it has only ever booted in qemu. on real hardware, you're the tester.

features

  • fully static userland
  • efistub boot
  • jits, a tiny binary package manager
  • lzfse compressed packages
  • cddl licensed, to annoy the fsf
  • 1000% gnu free
