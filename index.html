“The captive is the one whose desires hold him captive.”

yagni/linux is a static x86-64 linux distribution using musl libc and busybox.

features

  • no dynamic loader
  • 3 second base install
  • no /lib, no /sbin
  • efistub boot
  • 32 line boot
  • no systemd, udev, dbus
  • jits, a 166 line pkg manager
  • lzfse compressed packages
  • tcc links static
  • 1000% gnu free
