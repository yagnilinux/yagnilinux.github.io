This is blackout, an experimental Linux distribution for x86-64, built on musl libc and busybox. It has only been tested in QEMU. On real hardware, expect to find bugs.

rag
blackout's own package manager. Bottles come prebuilt, or built from source with the fuel your mix asks for.

s6 as init
The firmware starts the kernel, s6 starts the rest, and spark is the 49 lines in between. No bootloader, no initramfs.

Static
Every program. No dynamic loader, no /lib, no /sbin.

100% GNU free
Built with clang, lld and compiler-rt. Not almost, unlike a certain os.

barricade
The Wayland compositor, one C file on swc.

The odd ones
execline, samurai, muon, pdpmake, mandoc, oksh, doas.

Requirements:

  • An x86-64 machine that boots with UEFI, with secure boot disabled, or QEMU.
  • A USB stick.
  • Some experience with Linux.

Ready-to-boot images:

  • blackout.iso, 47MB. It boots to a root shell and carries everything needed to install.
  • blackout.tar.gz, 12MB, the base system.

Build your own from source:

  • https://github.com/yagnilinux/repo
