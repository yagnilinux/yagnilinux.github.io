“The captive is the one whose desires hold him captive.”

yagni/linux is a static x86-64 linux distribution using musl libc and busybox.

features

  • static, no dynamic loader
  • no /lib, no /sbin
  • efistub boot
  • 32 line boot script
  • no systemd, udev or dbus
  • jits, 165 line package manager
  • lzfse packages
  • tcc links static
  • 1000% gnu free
