This is requiem, an experimental Linux distribution for x86-64, built on musl libc and busybox. It has only been tested in QEMU. On real hardware, expect to find bugs.

Requirements:

  • An x86-64 machine that boots with UEFI, with secure boot disabled, or QEMU.
  • A USB stick.
  • Some experience with Linux.

Features:

  • Every program is statically linked. There is no dynamic loader and no /lib.
  • Everything is built with clang, lld and compiler-rt. requiem is 100% GNU free, unlike a certain os.
  • /usr is a symlink to /, and there is no /sbin. (the file system)
  • kyrie, a Wayland compositor built on swc.
  • No bootloader and no initramfs. The firmware starts the kernel, and init runs /etc/libera, a 32 line shell script.

Ready-to-boot images:

  • requiem.iso, 37MB. It boots to a root shell and carries everything needed to install.
  • requiem.tar.gz, 7MB, the base system.

Build your own from source:

  • https://codeberg.org/requiem-linux/repo
