“The captive is the one whose desires hold him captive.”

redemption/linux is a static x86-64 linux distribution using musl libc and busybox.

features

  • no dynamic loader
  • no /lib, no /sbin
  • efistub boot
  • 32 line boot
  • no systemd, udev, dbus
  • cook, 165 lines
  • lzfse compressed packages
  • tcc links static
  • 1000% gnu free
