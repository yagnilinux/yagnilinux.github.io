“The captive is the one whose desires hold him captive.”

this is yagni/linux, a static x86-64 linux distribution using musl libc and busybox.

requirements:

  • an x86-64 machine with uefi.
  • a usb stick and a free partition.
  • knowing your way around a shell.

features:

  • everything statically linked. no dynamic loader.
  • no /lib or /sbin. /usr is a symlink to /. (layout)
  • efistub boot.
  • jits, a 165 line package manager.
  • lzfse compressed packages.
  • 1000% gnu free. (lix)
