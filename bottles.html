Bottles

Missing something? Make a bottle and send it to the repo.

A bottle

$ ls crate/sys/qoltils
build  files  fuel  version
$ cat crate/sys/qoltils/fuel
+wifi    wifi network password, for wpa2
+vol     vol 80, sets and unmutes the sound
+yt      yt url, plays audio or downloads with yt-dlp
$ cat crate/sys/qoltils/build
#!/bin/sh -e
for f in mkuser etcnew; do install -Dm755 "$PKG/files/$f" "$1/usr/bin/$f"; done
[ -z "$F_wifi" ] || install -Dm755 "$PKG/files/wifi" "$1/usr/bin/wifi"
[ -z "$F_vol" ] || install -Dm755 "$PKG/files/vol" "$1/usr/bin/vol"
[ -z "$F_yt" ] || install -Dm755 "$PKG/files/yt" "$1/usr/bin/yt"
versionupstream version, then -1, -2. bump it on every change
buildinstalls into $1
sourcegit url tag, apt-src pkg or apt-deb pkg...
dependsone bottle per line
fuel+name on, -name off. $F_name in the build
appmakes it an app
binonlycan't be built on blackout

Building blackout

$ git clone https://github.com/yagnilinux/repo
$ cd repo
$ ./mkrepo
$ ./mkpkg scrawl
$ ./mkrootfs
# ./mkiso

The build machine needs clang, lld, compiler-rt, lzfse and GNU make, plus xorriso and mtools for the iso.
