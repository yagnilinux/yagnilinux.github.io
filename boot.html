how it boots

“Entities must not be multiplied beyond necessity.”
  — William of Ockham

  • every boot error on screen
  • the whole boot is one 32 line file

changing things

to change edit
boot /etc/init.d/rcS
consoles /etc/inittab
hostname /etc/hostname
mounts /etc/fstab
repository /etc/jits/repo
prompt /etc/profile

to start something at boot, add a line to rcS. systemd is 1.6 million lines, ships its own dns resolver, ntp client and bootloader, and lennart still isn't done. rcS fits on your screen, and it is done.

if it doesn't boot

stuck at Waiting for root device PARTLABEL=yagni? your root partition isn't named yagni. see installing.
