/boot/EFI/BOOT/BOOTX64.EFI is the kernel. its command line:

root=PARTLABEL=requiem rootwait rw init=/bin/init firmware_class.path=/share/firmware

busybox init runs /etc/init.d/rcS. to start something at boot, add a line.

boot -> /etc/init.d/rcS

consoles -> /etc/inittab

mounts -> /etc/fstab

hostname -> /etc/hostname

doas -> /etc/doas.conf

repository -> /etc/introit/repo
