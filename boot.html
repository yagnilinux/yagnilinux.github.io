-> boot

the firmware runs /boot/EFI/BOOT/BOOTX64.EFI, which is the kernel, with this command line compiled in:

root=PARTLABEL=yagni rootwait rw init=/bin/init firmware_class.path=/share/firmware

the kernel starts busybox init, which runs /etc/init.d/rcS. its 32 lines mount the filesystems, load a module for each device the kernel reports, start mdev and bring up the network. to start something at boot, add a line to it.

six files configure the system:

boot -> /etc/init.d/rcS

consoles -> /etc/inittab

mounts -> /etc/fstab

hostname -> /etc/hostname

who gets root -> /etc/doas.conf

repository -> /etc/jits/repo
