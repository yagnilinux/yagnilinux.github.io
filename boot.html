-> boot

“Very little is needed to make a happy life.” — Marcus Aurelius

the firmware runs /boot/EFI/BOOT/BOOTX64.EFI, which is the kernel. its command line is compiled in:

root=PARTLABEL=requiem rootwait rw init=/bin/init firmware_class.path=/share/firmware

the kernel starts busybox init, which runs /etc/init.d/rcS. its 32 lines mount the filesystems, load a module for each device the kernel reports, start mdev and bring up the network. to start something at boot, add a line to it.

six files configure the system:

boot -> /etc/init.d/rcS

consoles -> /etc/inittab

mounts -> /etc/fstab

hostname -> /etc/hostname

root access -> /etc/doas.conf

repository -> /etc/introit/repo
