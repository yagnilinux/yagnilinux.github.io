[01] use

cook is one shell script, 165 lines long.

cook [-r root] [a|r|u|s|l] [pkg]...
  a  add       install packages and what they need
  r  remove    remove packages
  u  update    sync the repository, upgrade everything
  s  search    search the repository
  l  list      list installed packages

the repository holds one version of every package, so cook never picks between versions. packages are tarballs compressed with apple's lzfse, which unpacks ffmpeg in 39ms where gzip takes 177ms. cook checks every package against the sha256 in the index before installing it. nothing is signed.

cook removes what you tell it to, including what other packages need. configs survive upgrades: the new version lands as file.new, and etcnew merges it.

another repository goes in /etc/cook/repo, or in COOK_REPO for one command, and file:// works. to find the package that owns a file:

$ grep -lx bin/oksh /var/db/cook/installed/*/manifest

[02] packaging

a package is a directory in pkgs/ of redemption-linux/repo:

pkgs/bluesky/version    0.3
pkgs/bluesky/source     git https://codeberg.org/redemption-linux/bluesky.git main
pkgs/bluesky/build      #!/bin/sh -e
                    musl-gcc -std=c99 -Os -s -static -o bluesky bluesky.c
                    install -Dm755 bluesky "$1/bin/bluesky"
pkgs/bluesky/depends    what it needs, one per line
pkgs/bluesky/files/     configs and patches

build installs into $1 as if it were /, following the layout, and everything it installs is static and stripped. sources are git <url> <tag>, apt-src <pkg> or apt-deb <pkg>. when you change a package, bump its version; superlab refuses to rebuild a changed package under the old one.

[03] building redemption

$ git clone https://codeberg.org/redemption-linux/repo
$ cd repo
$ ./superlab      # every package into repo/
$ ./mkrootfs    # redemption.tar.gz
# ./mkiso       # redemption.iso

build on another linux machine. the kernel needs gnu make, and gnu doesn't go on redemption. the build machine needs musl-gcc and lzfse. mkiso needs root, xorriso and mtools. any web server serving repo/ is a mirror.
