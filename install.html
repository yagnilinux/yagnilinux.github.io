-> install

“It is not the man who has too little, but the man who craves more, that is poor.” — Seneca

write requiem.iso to a usb stick and boot it with secure boot off. it starts a root shell. the install does not need a network.

# dd if=requiem.iso of=/dev/sdX bs=4M

the kernel finds root by its gpt partition name, so the root partition must be named requiem.

# sfdisk /dev/sda <<EOF
label: gpt
size=256M, type=uefi, name=BOOT
type=linux, name=requiem
EOF
# mkfs.vfat -F 32 -n BOOT /dev/sda1
# mkfs.ext4 -L requiem /dev/sda2
# mount /dev/sda2 /mnt
# mkdir /mnt/boot
# mount /dev/sda1 /mnt/boot

unpack the base system and set a root password. tar will warn about permissions on /boot, which is fat; the warnings are harmless.

# cd /media/install
# sha256sum -c requiem.tar.gz.sha256
# tar xzf requiem.tar.gz -C /mnt
# chroot /mnt passwd

on a machine with only wifi, install the wifi packages from the iso before rebooting:

# INTROIT_REPO=file:///media/install/repo introit -r /mnt a wpa_supplicant firmware-iwlwifi yutils
# umount /mnt/boot /mnt
# reboot

when it does not boot

Waiting for root device PARTLABEL=requiem: the partition name is wrong. sfdisk --part-label /dev/sda 2 requiem.

firmware that will not boot the fallback path from an internal disk: add an entry with efibootmgr from another live system.

dual boot: mount the existing efi partition at /mnt/boot, and move any EFI/BOOT/BOOTX64.EFI aside first. requiem installs its kernel there.
