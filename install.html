install

write yagni.iso to a usb stick, turn off secure boot and boot it. no network needed.

-> dd if=yagni.iso of=/dev/sdX bs=4M

root is the gpt partition named yagni.

-> sfdisk /dev/sda <<EOF
label: gpt
size=256M, type=uefi, name=BOOT
type=linux, name=yagni
EOF
-> mkfs.vfat -F 32 -n BOOT /dev/sda1
-> mkfs.ext4 -L yagni /dev/sda2
-> mount /dev/sda2 /mnt
-> mkdir /mnt/boot
-> mount /dev/sda1 /mnt/boot

unpack base, set a root password. ignore tar's complaints about /boot.

-> cd /media/install
-> sha256sum -c yagni.tar.gz.sha256
-> tar xzf yagni.tar.gz -C /mnt
-> chroot /mnt passwd

wifi only? install wifi before rebooting:

-> JITS_REPO=file:///media/install/repo jits -r /mnt a wpa_supplicant firmware-iwlwifi yutils
-> umount /mnt/boot /mnt
-> reboot

when it does not boot

Waiting for root device: sfdisk --part-label /dev/sda 2 yagni.

firmware ignores the disk: add an entry with efibootmgr.

dual boot: mount the existing efi partition at /mnt/boot. yagni overwrites EFI/BOOT/BOOTX64.EFI.
