install

boot yagni.iso from a usb stick with uefi. secure boot off. you get a root shell. nothing here needs the network.

# dd if=yagni.iso of=/dev/sdX bs=4M

root is found by the gpt partition name yagni. nothing else works.

# sfdisk /dev/sda <<EOF
label: gpt
size=256M, type=uefi, name=BOOT
type=linux, name=yagni
EOF
# mkfs.vfat -F 32 -n BOOT /dev/sda1
# mkfs.ext4 -L yagni /dev/sda2
# mount /dev/sda2 /mnt
# mkdir /mnt/boot
# mount /dev/sda1 /mnt/boot

unpack base and set a root password. tar complains about permissions on /boot because it is fat. ignore it.

# cd /media/install
# sha256sum -c yagni.tar.gz.sha256
# tar xzf yagni.tar.gz -C /mnt
# chroot /mnt passwd

wifi only: install it from the iso before rebooting. see wifi.

# JITS_REPO=file:///media/install/repo jits -r /mnt a wpa_supplicant firmware-iwlwifi yutils
# umount /mnt/boot /mnt
# reboot

when it does not boot

Waiting for root device PARTLABEL=yagni: the partition name is wrong. sfdisk --part-label /dev/sda 2 yagni.

firmware that will not boot the fallback path from an internal disk: add an entry with efibootmgr from another live system.

dual boot: mount the existing efi partition at /mnt/boot. move any EFI/BOOT/BOOTX64.EFI out of the way first. yagni overwrites it.
