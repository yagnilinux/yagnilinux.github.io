“It is not the man who has too little, but the man who craves more, that is poor.” — Seneca

secure boot off. no network needed.

# dd if=requiem.iso of=/dev/sdX bs=4M

boot it. the root partition has to be named requiem.

# sfdisk /dev/sda <<EOF
label: gpt
size=256M, type=uefi, name=BOOT
type=linux, name=requiem
EOF
# mkfs.vfat -F 32 -n BOOT /dev/sda1
# mkfs.ext4 -L requiem /dev/sda2
# mount /dev/sda2 /mnt
# mkdir /mnt/boot
# mount /dev/sda1 /mnt/boot
# cd /media/install
# sha256sum -c requiem.tar.gz.sha256
# tar xzf requiem.tar.gz -C /mnt
# chroot /mnt passwd

tar complains about /boot. ignore it.

wifi only:

# INTROIT_REPO=file:///media/install/repo introit -r /mnt a wpa_supplicant firmware-iwlwifi yutils
# umount /mnt/boot /mnt
# reboot

IT DOESN'T BOOT

Waiting for root device PARTLABEL=requiem:

# sfdisk --part-label /dev/sda 2 requiem

internal disk ignored: add it with efibootmgr from another live system.

dual boot: mount the existing efi partition on /mnt/boot. move EFI/BOOT/BOOTX64.EFI out of the way first.
