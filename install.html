-> install

write redemption.iso to a usb stick and boot it with secure boot off. it drops you in a root shell, and the install doesn't need a network.

# dd if=redemption.iso of=/dev/sdX bs=4M

the kernel finds root by its gpt partition name, so the second partition has to be called redemption.

# sfdisk /dev/sda <<EOF
label: gpt
size=256M, type=uefi, name=BOOT
type=linux, name=redemption
EOF
# mkfs.vfat -F 32 -n BOOT /dev/sda1
# mkfs.ext4 -L redemption /dev/sda2
# mount /dev/sda2 /mnt
# mkdir /mnt/boot
# mount /dev/sda1 /mnt/boot

unpack base and set a root password. tar complains about permissions on /boot because it is fat; ignore it.

# cd /media/install
# sha256sum -c redemption.tar.gz.sha256
# tar xzf redemption.tar.gz -C /mnt
# chroot /mnt passwd

on a machine with only wifi, install wifi from the iso before rebooting:

# COOK_REPO=file:///media/install/repo cook -r /mnt a wpa_supplicant firmware-iwlwifi yutils
# umount /mnt/boot /mnt
# reboot

when it does not boot

Waiting for root device PARTLABEL=redemption: the partition name is wrong. sfdisk --part-label /dev/sda 2 redemption.

firmware that will not boot the fallback path from an internal disk: add an entry with efibootmgr from another live system.

dual boot: mount the existing efi partition at /mnt/boot and move any EFI/BOOT/BOOTX64.EFI out of the way first, because redemption writes its kernel there.
