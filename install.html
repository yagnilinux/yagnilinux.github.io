Installing

You need an x86-64 machine with UEFI and a USB stick.

The stick

To write blackout.iso to it:

# dd if=blackout.iso of=/dev/sdX bs=4M

Turn secure boot off and boot it.

The disk

To make an EFI partition and a root partition. The root partition has to be named blackout:

# sfdisk /dev/sda <<EOF
label: gpt
size=256M, type=uefi, name=BOOT
type=linux, name=blackout
EOF
# mkfs.vfat -F 32 -n BOOT /dev/sda1
# mkfs.ext4 -L blackout /dev/sda2
# mount /dev/sda2 /mnt
# mkdir /mnt/boot
# mount /dev/sda1 /mnt/boot

To dual boot, mount your existing EFI partition at /mnt/boot instead.

The base

# cd /media/install
# sha256sum -c blackout.tar.gz.sha256
# tar xzf blackout.tar.gz -C /mnt
# chroot /mnt passwd

Wifi, before rebooting

# RAG_REPO=file:///media/install/repo rag -r /mnt a net/wpa_supplicant firmware/iwlwifi sys/qoltils

firmware/realtek instead of firmware/iwlwifi for Realtek cards.

Reboot

# umount /mnt/boot /mnt
# reboot

Stuck at Waiting for root device PARTLABEL=blackout:

# sfdisk --part-label /dev/sda 2 blackout

The firmware skips the disk:

# efibootmgr -c -d /dev/sda -p 1 -L blackout -l '\\EFI\\BOOT\\BOOTX64.EFI'
