installing

there is no installer. you partition a disk, untar a tarball and set a password. if you've installed arch, you've done harder. if that still sounds like too much, the answers page has an installer for you.

1. boot something

boot any linux live usb on an x86_64 machine with uefi. turn secure boot off. get online.

2. partition

name them exactly like this. the kernel finds root by its name and it won't guess.

partition size type gpt name
1 256MB EFI System BOOT
2 the rest Linux yagni 
# sfdisk /dev/sda <<EOF
label: gpt
size=256M, type=uefi, name=BOOT
type=linux, name=yagni
EOF

3. filesystems

# mkfs.vfat -F 32 -n BOOT /dev/sda1
# mkfs.ext4 -L yagni /dev/sda2

4. mount

# mount /dev/sda2 /mnt
# mkdir /mnt/boot
# mount /dev/sda1 /mnt/boot

5. the tarball

# cd /tmp
# wget https://yagnilinux.github.io/packages/yagni.tar.gz
# wget https://yagnilinux.github.io/packages/yagni.tar.gz.sha256
# sha256sum -c yagni.tar.gz.sha256
# tar xzf yagni.tar.gz -C /mnt

tar warns about permissions on /boot. it's fat, ignore it.

6. root password

# chroot /mnt /usr/bin/passwd

7. wifi, if you need it

skip this on ethernet. realtek cards want firmware-realtek instead.

# cp /etc/resolv.conf /mnt/etc/
# chroot /mnt /usr/bin/jits a wpa_supplicant firmware-iwlwifi yutils
# wpa_passphrase "network" "password" > /mnt/etc/wpa_supplicant.conf

8. reboot

# umount /mnt/boot /mnt
# reboot

9. a user

log in as root and add a user.

# jits a yutils
# mkuser foo

log out, log back in as foo.

it didn't boot

some firmware won't boot the fallback path off an internal disk. give it an entry from the live system:

# efibootmgr -c -d /dev/sda -p 1 -L YAGNI -l '\EFI\BOOT\BOOTX64.EFI'

stuck at Waiting for root device PARTLABEL=yagni? you misnamed the second partition. sfdisk --part-label /dev/sda 2 yagni.

dual booting

mount the efi partition you already have at /mnt/boot instead of making one. if /boot/EFI/BOOT/BOOTX64.EFI is already there, move it out of the way first and give yagni its own entry with efibootmgr.
