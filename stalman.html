stallman

richard stallman started gnu in 1983. it gave the world gcc, a libc, coreutils and a license. its own kernel, hurd, has been in development since 1990. linux showed up in 1991 and won.

the name

gnu wants you to call it gnu/linux. the kernel was written by someone else and the systems people actually run are put together by distributions, but the toolchain's author still wants top billing. yagni has no gnu in it, so it gets to be yagni/linux instead. see answers.

why i hate gnu

  • glibc fights static linking, and yagni is static.
  • the gpl spreads. link gpl code into your program, ship it, and your program has to be gpl too. yagni uses the cddl, the license sun wrote for solaris. change my file, share my file. your code stays yours. the fsf calls it gpl-incompatible, which is the nicest thing they've ever said about me.
  • gnu extensions leak into everything. half the shell scripts on the internet break the second you run them without gnu sed, gnu grep or bash.
  • gnu tools are big. coreutils is around a hundred separate programs. busybox does that job, plus the shell, in one binary.

  • and the name. the kernel isn't gnu's and the distributions aren't gnu's, but you're still supposed to say gnu/linux.

  • and freedom. the fsf wants you to serve it, defend it and sign your code over to it. if you have to serve it, it isn't yours. stirner called that a spook.

so the compiler is tcc, the shell and userland are busybox, and the libc is musl. where something needed a gnu library, i took a bsd one instead.

i googled him

i typed "stalman" into a search engine to find a photo for this page. it gave me tyler stalman, a photographer with great glasses. richard didn't come up. i'm choosing to take that as a sign.
