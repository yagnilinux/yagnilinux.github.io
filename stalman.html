richard stallman started gnu in 1983. it gave the world gcc, a libc, coreutils and a license. its own kernel, hurd, has been in development since 1990. linux showed up in 1991 and won.

the name

gnu wants you to call it gnu/linux. the kernel was written by someone else and the systems people actually run are put together by distributions, but the toolchain's author still wants top billing. requiem has no gnu in it, so it gets to be requiem/linux instead. see answers.

why we hate gnu

  • glibc fights static linking, and requiem is static.
  • the gpl spreads. link gpl code into your program, ship it, and your program has to be gpl too. requiem uses the cddl, the license sun wrote for solaris. change our file, share our file. your code stays yours. the fsf calls it gpl-incompatible, which is the nicest thing they've ever said about us.
  • gnu extensions leak into everything. half the shell scripts on the internet break the second you run them without gnu sed, gnu grep or bash.
  • gnu tools are big. coreutils is around a hundred separate programs. busybox does that job, plus the shell, in one binary.
  • and the name. it has been "gnu/linux" for thirty years and it still hasn't caught on.

so the compiler is tcc, the shell and userland are busybox, and the libc is musl. where something needed a gnu library, we took a bsd one instead.

we googled him

we typed "stalman" into a search engine to find a photo for this page. it gave us tyler stalman, a photographer with great glasses. richard didn't come up. we're choosing to take that as a sign.

requiem is free software. free as in free of gnu.
