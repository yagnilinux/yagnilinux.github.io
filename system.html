The system

The file system

/bin        programs
/share      data, fonts, firmware, modules, headers, static libraries
/etc        configuration
/boot       the EFI partition and the kernel
/var        logs and /var/db/rag
/apps       apps for every user
/home       users and their ~/apps
/usr        symlink to /

Everything is static. No /lib, no /sbin, nothing built for glibc.

Apps

Apps are folders in ~/apps, or /apps for everyone.

$ rag a browsers/netsurf
# rag a browsers/netsurf
$ mv ~/apps/netsurf ~/old/

spark and s6

The firmware runs the kernel, the kernel runs s6-linux-init, and s6 runs /etc/spark, 49 lines of shell. No bootloader, no initramfs.

To add a service:

# mkdir /etc/sv/foo
# printf '#!/bin/sh\nexec foo -f\n' > /etc/sv/foo/run
# chmod +x /etc/sv/foo/run
# ln -s /etc/sv/foo /run/service/
# s6-svc -r /run/service/foo
$ s6-svstat /run/service/foo

Wifi

$ cat /sys/bus/pci/devices/*/vendor
# wifi network password

0x8086 needs firmware/iwlwifi, 0x10ec needs firmware/realtek. WPA2 only.
