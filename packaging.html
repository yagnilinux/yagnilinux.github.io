packaging

packaging is easy. to add your own software to yagni, make a directory in pkgs/ and fill in up to four files. if you've written a kiss package, you already know how.

pkgs/<name>/version     the version
pkgs/<name>/depends     what it needs, one per line (optional)
pkgs/<name>/source      where to get it (optional)
pkgs/<name>/build       how to build it

build

a shell script that installs the program into $1, as if $1 were /. $PKG is your package's directory, for configs and patches.

build it static (musl-gcc -static) and strip it, so it keeps working whatever else gets upgraded.

source

git <url> <tag>          a git repository
apt-src <pkg>            an ubuntu source package
apt-deb <pkg>...         ubuntu binary packages (firmware only)

your own repository

$ ./mkrepo      # build your packages
$ ./mkrootfs    # build an install tarball

bump version whenever you change a package, or nobody gets the change. mkrepo won't let you forget.

put repo/ on any web server and point /etc/jits/repo at it. that's a distribution.
