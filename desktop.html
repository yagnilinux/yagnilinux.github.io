# cook a deadeye netsurf wallpaper
$ startw

deadeye is the compositor: floating windows, four workspaces, 179 lines of c on swc. havoc is the terminal.

super+return -> terminal

super+d -> dmenu

super+q -> close a window

super+1-4 -> workspace

super+p -> screenshot

colours and keys come from two files, so nothing gets recompiled:

~/.config/deadeye/env
DEADEYE_BORDER=6
DEADEYE_FOCUS=3d6fa3
DEADEYE_UNFOCUS=253e5b

~/.config/deadeye/keys
case $1 in
w) exec netsurf ;;
S-x) exec havoc bluesky ;;
esac

setwall picks the wallpaper. us keyboard layout only.
