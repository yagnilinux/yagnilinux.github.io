# jits a luwm netsurf wallpaper
$ startw

the terminal is havoc and the shell you type in is oksh, openbsd's korn shell. scripts still run on busybox's ash, so underneath it's ash and havoc. we didn't plan that, but we're keeping it.

super + return opens havoc, super + d opens dmenu. the other keys are on the luwm page.

wallpaper

$ setwall /usr/share/wallpapers/tide.png
$ setwall '#1a4270'

screenshots

$ snap shot.png

or super + p.

ricing

~/.config/luwm/env:

LUWM_BORDER=6
LUWM_FOCUS=3d6fa3
LUWM_UNFOCUS=253e5b
TERMINAL="havoc -c ~/.config/havoc.cfg"
MENU="dmenu_run -fn 'IM FELL English:size=18'"

~/.config/luwm/keys is a shell script. super + x runs it with x, super + shift + x with S-x:

case $1 in
w) exec netsurf ;;
S-x) exec havoc -e yte ;;
esac

want other fonts? jits a font-kirsch font-imfell.
