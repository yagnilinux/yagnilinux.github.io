jits

“It is not the man who has too little, but the man who craves more, that is poor.”
  — Seneca

jits (just install that shit) is the package manager. under 180 lines. one version of every package, so no dependency hell.

jits [-r root] [a|r|u|s|l] [pkg]...

  a  add       install a package and its dependencies
  r  remove    remove a package
  u  update    sync the repository, upgrade everything
  s  search    search the repository
  l  list      list installed packages

-r /mnt does the same to a system mounted somewhere else.

what to expect

  • one command installs a package and everything it needs
  • your configs survive upgrades (etcnew merges the new ones)
  • remove anything. you're an adult

example

$ jits s yt
python 3.13.9-1
yt-dlp 2026.10.26-1
yte 0.3
$ jits a yte
-> repo Synced
-> yte Installed 0.3

jits a yt-dlp pulls in python, quickjs and ffmpeg on its own. jits r yte takes it back out.

using another repository

set JITS_REPO, or put the address in /etc/jits/repo. the default is https://yagnilinux.github.io/packages. anyone can run a repository, see packaging.

which package owns a file

$ grep -lx usr/bin/fastfetch /var/db/jits/installed/*/manifest
