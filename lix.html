= lix

take linux and remove the gnu. what's left is lix. richard wants it called gnu/linux. we went the other way.

WHAT WAS REMOVED

glibc -> musl

coreutils, grep, sed, gawk, findutils, diffutils, tar, gzip -> busybox

bash -> oksh, from openbsd

ncurses -> netbsd-curses

bc -> gavin howard's bc, as in freebsd

grub -> nothing. the kernel is the efi program

gcc -> clang and lld build everything. tcc ships for your own code

libgcc -> compiler-rt

readline -> nothing

make -> nothing

WHAT IS GPL

almost everything in the gnu column is gplv3. glibc is lgpl, and ncurses isn't gpl at all, but gnu keeps it anyway.

linux is gplv2 only. linus turned down v3 in 2007 and never moved. there is no gplv3 in base either.

gpl is a license. gnu is a project. a package may be gpl. it may not be gnu.
