1 Installing

You need an x86-64 machine with UEFI, a USB stick, and requiem.iso.

1.1 Writing the stick

To write the iso to a stick:

# dd if=requiem.iso of=/dev/sdX bs=4M

NOTE: Check the device name with lsblk first. Everything on it is overwritten.

Turn secure boot off and boot from the stick. It starts a root shell.

1.2 Partitioning the disk

To make an EFI partition and a root partition named requiem:

# sfdisk /dev/sda <<EOF
label: gpt
size=256M, type=uefi, name=BOOT
type=linux, name=requiem
EOF

NOTE: The root partition must be named requiem. That name is how the kernel finds it.

To format and mount them:

# mkfs.vfat -F 32 -n BOOT /dev/sda1
# mkfs.ext4 -L requiem /dev/sda2
# mount /dev/sda2 /mnt
# mkdir /mnt/boot
# mount /dev/sda1 /mnt/boot

To dual boot, mount the EFI partition you already have at /mnt/boot instead, and move its EFI/BOOT/BOOTX64.EFI somewhere else.

1.3 Unpacking the base system

To check and unpack the base system:

# cd /media/install
# sha256sum -c requiem.tar.gz.sha256
# tar xzf requiem.tar.gz -C /mnt

NOTE: tar warns about permissions on /boot. FAT has none. Ignore it.

To set the root password:

# chroot /mnt passwd

1.4 Before rebooting

To get wifi on the new system, install it from the stick. Use firmware/realtek instead of firmware/iwlwifi for a Realtek card:

# INTROIT_REPO=file:///media/install/repo introit -r /mnt a net/wpa_supplicant firmware/iwlwifi sys/qoltils

To reboot:

# umount /mnt/boot /mnt
# reboot

1.5 If it does not boot

If it stops at Waiting for root device PARTLABEL=requiem, rename the root partition:

# sfdisk --part-label /dev/sda 2 requiem

If the firmware skips the disk, add a boot entry from another live system:

# efibootmgr -c -d /dev/sda -p 1 -L requiem -l '\\EFI\\BOOT\\BOOTX64.EFI'

2 introit

introit is the package manager. It is a shell script of 177 lines. Source: requiem-linux/introit.

introit [-r root] a|r|u|s|l [pkg]...

2.1 Installing packages

To install git:

# introit a dev/git

To install it without typing the category:

# introit a git

NOTE: If two categories have a package with that name, introit asks which one you mean.

To install into a system mounted at /mnt:

# introit -r /mnt a dev/git

To install from another repository for one command:

# INTROIT_REPO=file:///media/install/repo introit a dev/git

2.2 Finding packages

To see every package in the repository:

$ introit s

To search for one:

$ introit s fetch

To see what is installed:

$ introit l

To find which package a file came from:

$ grep -lx bin/oksh /var/db/introit/installed/*/*/manifest

The full list with sizes is on the packages page.

2.3 Removing packages

To remove pfetch:

# introit r utils/pfetch

NOTE: introit does not check whether something else needs the package.

2.4 Updating

To update everything:

# introit u

NOTE: Packages are checked against the sha256 in the index, but nothing is signed. Use a repository you trust.

2.5 Edited files in /etc

Files you edited in /etc are kept on update, and the new version is saved as file.new. To list them:

$ etcnew

To compare, take or drop the new /etc/profile:

$ etcnew diff /etc/profile
# etcnew take /etc/profile
# etcnew keep /etc/profile

2.6 /var/db/introit

/var/db/introit/repo/index                    the index
/var/db/introit/installed/<category>/<name>/  version, depends, manifest, etcsums
/var/db/introit/cache                         downloads, safe to empty
/var/db/introit/stage                         unpacking, safe to empty

Users without root get the index and cache in ~/.cache/introit. Apps are not recorded here.


3 The system

3.1 The file system

/bin        programs
/share      data, fonts, firmware, modules, headers, static libraries
/etc        configuration
/boot       the EFI partition and the kernel
/var        logs and /var/db/introit
/apps       apps for every user
/home       users and their ~/apps
/usr        symlink to /

Everything is static. There is no /lib and no /sbin, and programs built for glibc do not run.

Apps are folders in ~/apps. They install into your home, so no root is needed. To install netsurf:

$ introit a browsers/netsurf

To install it for every user, in /apps:

# introit a browsers/netsurf

To uninstall an app, move its folder out of ~/apps. To get it back, move it back. Log in again after either.

$ mv ~/apps/netsurf ~/old/

NOTE: If an app needs something from the base system, introit prints the doas introit a ... line to run first.

The apps in the repository are browsers/netsurf and terminals/havoc.

To build your own code, install dev/tcc and sys/musl-dev:

$ tcc -static -o hello hello.c

3.2 libera

libera is the boot. The firmware runs the kernel from /boot/EFI/BOOT/BOOTX64.EFI, and busybox init runs /etc/libera, which is 32 lines. There is no bootloader, no initramfs and no services.

To start something at every boot, add it to the end of /etc/libera.

/etc/liberathe boot
/etc/inittabconsoles
/etc/fstabmounts
/etc/hostnamehostname
/etc/doas.confwho can use doas
/etc/introit/repothe repository
/etc/profilePATH and the prompt

To read kernel messages:

$ dmesg

3.3 Users

To add a user that can use doas (needs sys/qoltils):

# mkuser foo

3.4 Wifi

To find out which firmware you need:

$ cat /sys/bus/pci/devices/*/vendor

0x8086 is Intel, use firmware/iwlwifi. 0x10ec is Realtek, use firmware/realtek.

To connect:

# wifi network password

NOTE: Only WPA2. WPA3 and enterprise networks do not work. Wired and USB tethering get an address at boot if plugged in.

3.5 Sound

To turn sound on (needs sound/alsa-utils):

$ vol 80

4 The desktop

kyrie is the Wayland compositor of requiem. To install it and start it:

# introit a desktop/kyrie desktop/wallpaper
$ startw

To change the colours, the border and the programs on super + return, d and w, edit ~/.config/kyrie/env:

KYRIE_BORDER=6
KYRIE_FOCUS=c9c9c6
KYRIE_UNFOCUS=494949
TERMINAL=havoc
MENU=dmenu_run
BROWSER=netsurf

To add your own keys, copy /share/kyrie/keys to ~/.config/kyrie/keys and add a line:

case $1 in
w) exec netsurf ;;
S-x) exec havoc tract ;;
esac

To set a wallpaper:

$ setwall /share/wallpapers/tower.png
$ setwall '#1a4270'

To take a screenshot, press super + p, or:

$ shot file.png

NOTE: Only the US keyboard layout is included.

5 Writing packages

If something is missing, package it and send a pull request to the repo.

5.1 A package

A package is a folder in pkgs/<category>/. This is pkgs/utils/pfetch:

$ cat pkgs/utils/pfetch/version
0.6.1-2
$ cat pkgs/utils/pfetch/source
git https://github.com/dylanaraps/pfetch master
$ cat pkgs/utils/pfetch/build
#!/bin/sh -e
install -Dm755 pfetch "$1/usr/bin/pfetch"
versionrequired. upstream version, then -1, -2 for rebuilds
buildrequired. installs into $1
sourcegit url tag, apt-src pkg or apt-deb pkg...
dependsone package per line, with its category
appempty file. makes it an app

NOTE: Change version every time you change the package, or nobody gets the change. mkrepo refuses to build it otherwise.

5.2 Building

To build every package, the base system and the iso:

$ git clone https://codeberg.org/requiem-linux/repo
$ cd repo
$ ./mkrepo
$ ./mkrootfs
# ./mkiso

To build only one package:

$ ./mkpkg tract

The build machine needs clang, lld, compiler-rt, lzfse and GNU make. mkiso also needs xorriso and mtools.


NOTE: GNU make is only used to build the kernel. cc/gcc is a stub that fails, so nothing from gcc ends up in a package.
