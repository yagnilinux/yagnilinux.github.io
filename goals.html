  • users know what they are doing.

  • the whole system stays small enough for one person to read.

SPOOKS

you were told a real system needs these.

a bootloader
uefi starts the kernel itself.

an initramfs
the kernel mounts root directly.

systemd
busybox init and one boot script.

udev
busybox mdev.

shared libraries
everything is static.

NetworkManager
one file. it connects at every boot.

snap and flatpak
a folder in ~/apps. your calculator doesn't need its own copy of gtk.

electron
programs that aren't a whole chromium wearing a trench coat.

dbus
programs that can talk without a message bus in the middle.

EXPECTATIONS

requiem is small because the people using it help build it. before you install it, you should know this:

  • it's installed and set up by hand. you'll partition a disk, edit files in /etc and read shell scripts.
  • the documentation is short, and so is the code. most answers are in one of them.
  • the repository won't have everything. if something's missing, package it and send it back.
  • a bug report needs what you ran, what happened and the full output.
  • things change between releases. when something gets dropped, the commit says why.
  • nothing here is sacred. not the docs, not the code. if something's wrong, say so.
  • if you want hand-holding, linux mint exists and it's lovely. go there.
