goals

a goal that can be quoted to excuse a bad decision was written badly. these are meant to be hard to misuse.

  • users know what they are doing.
  • users take part. package what's missing and send it back. if you contribute, i will see it.
  • the whole system stays small enough for one person to read.
  • base is what a machine needs to boot and install packages. nothing else.
  • a script you can read beats a daemon you have to trust.
  • things get broken when keeping them means keeping complexity.

spooks

every one of these is a fixed idea. you were told a real system needs them, so you serve them. it doesn't, so i don't.

a bootloader uefi starts the kernel itself.
an initramfs the kernel mounts root directly.
systemd busybox init and one boot script.
udev busybox mdev.
shared libraries base is static.
NetworkManager one file. it connects at every boot.
a desktop base boots to a shell. the window manager is a package.
snap and flatpak a tarball of files. your calculator doesn't need its own copy of gtk.
electron programs that aren't a whole chromium wearing a trench coat.
dbus programs that can talk without a message bus in the middle.
