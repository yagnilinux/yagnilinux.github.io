-> goals

“Perfection is achieved not when there is nothing more to add, but when there is nothing left to take away.”

  • you know what you're doing. or you will soon.
  • a program starts the moment you ask for it. nothing loads in between.
  • nothing runs that you didn't start.
  • one person can read the whole system in a weekend. a long one, but still.
  • base boots the machine and installs packages. that's it, that's base.
  • a script you can read beats a daemon you have to trust.
  • things get broken when keeping them is more work than breaking them.

what we expect from you

every user of yagni is a developer of yagni. nobody asked for this, least of all you.

  • you read the docs first. they're short, we made sure.
  • you read the script before you blame it. jits is 166 lines, it'll take ten minutes.
  • something missing? package it and send it back. asking is allowed, it just works less often.
  • bug reports come with the command you ran and what it printed. "it doesn't work" is not a command.
  • when someone helping you asks for something, give them that and not the thing next to it.
