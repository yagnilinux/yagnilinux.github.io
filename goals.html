-> goals

“Man, your head is haunted; you have wheels in your head!” — Max Stirner, The Ego and Its Own

  • users know what they are doing.
  • users take part. what's missing, they package.
  • small enough for one person to read.
  • the base boots the machine and installs packages. nothing else.
  • a script you can read beats a daemon you have to trust.
  • compatibility goes when it costs complexity.

SPOOKS

a bootloader
the firmware starts the kernel.

an initramfs
the kernel mounts root.

systemd
busybox init.

udev
mdev.

shared libraries
no.

NetworkManager
one file.

flatpak
a folder in ~/apps.

dbus
no.

EXPECTATIONS

  • read the docs before asking.
  • read the script before reporting a bug in it.
  • package what's missing and send it back.
  • bug reports have the command and what it printed.
  • when someone helping you asks for something, give them that.
