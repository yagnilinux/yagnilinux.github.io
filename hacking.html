hacking

“Talk is cheap. Show me the code.”
  — Linus Torvalds

rebuild the whole distribution with two commands. it's all in yagnilinux/repo.

$ git clone https://github.com/yagnilinux/repo
$ cd repo
$ ./mkrepo
$ ./mkrootfs

rules

  • shell is posix sh.
  • programs are static against musl libc.
  • a package that needs a library builds it itself.
  • base is what a machine needs to boot and install packages. everything else is a package.

testing

install the tarball on a fresh disk in qemu, install every package, log in as a normal user and start the desktop. if that works, send it.

sending changes

pull request against yagnilinux/repo. bump version in every package you touch. if your patch adds a dependency, the commit message says why.
