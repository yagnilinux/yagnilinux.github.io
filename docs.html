[01] install

write yagni.iso to a usb stick and boot it with uefi. secure boot has to be off. you land in a root shell.

# dd if=yagni.iso of=/dev/sdX bs=4M

partition the disk. the kernel finds root by the gpt partition name yagni and by nothing else. name it anything else and it will not boot.

# sfdisk /dev/sda <<EOF
label: gpt
size=256M, type=uefi, name=BOOT
type=linux, name=yagni
EOF
# mkfs.vfat -F 32 -n BOOT /dev/sda1
# mkfs.ext4 -L yagni /dev/sda2
# mount /dev/sda2 /mnt
# mkdir /mnt/boot
# mount /dev/sda1 /mnt/boot

unpack base and set a root password:

# cd /media/install
# sha256sum -c yagni.tar.gz.sha256
# tar xzf yagni.tar.gz -C /mnt
# chroot /mnt passwd

tar will complain about permissions on /boot. it's fat, ignore it. if your machine only has wifi, install it from the iso now, see [05]:

# JITS_REPO=file:///media/install/repo jits -r /mnt a wpa_supplicant firmware-iwlwifi yutils
# umount /mnt/boot /mnt
# reboot

if the boot stops at Waiting for root device PARTLABEL=yagni, you named the partition wrong. fix it with sfdisk --part-label /dev/sda 2 yagni. some firmware refuses to boot the fallback path from an internal disk. in that case, add a boot entry with efibootmgr from another live system. if you dual boot, mount your existing efi partition at /mnt/boot instead of making a new one, and move any EFI/BOOT/BOOTX64.EFI already there out of the way first, or you will overwrite it.

[02] boot

the firmware starts the kernel directly from /boot/EFI/BOOT/BOOTX64.EFI. the kernel carries its own command line, root=PARTLABEL=yagni rootwait rw. the kernel mounts root and starts busybox init, which runs /etc/init.d/rcS. that file is the entire boot, 32 lines long. to start something at boot, add a line to it. these files are everything that configures the system:

boot/etc/init.d/rcS
consoles/etc/inittab
mounts/etc/fstab
hostname/etc/hostname
who gets root/etc/doas.conf
repository/etc/jits/repo

[03] jits

just install that shit. one shell script, 165 lines.

jits [-r root] [a|r|u|s|l] [pkg]...
  a  add       install packages and what they need
  r  remove    remove packages
  u  update    sync the repository, upgrade everything
  s  search    search the repository
  l  list      list installed packages

the repository holds exactly one version of every package, so there is no dependency resolution. packages are tarballs compressed with apple's lzfse, which unpacks about four times faster than gzip. the index carries a sha256 for every package and jits checks it before installing. nothing is signed.

jits will remove whatever you tell it to, including things other packages depend on. it assumes you meant it. configs survive upgrades: a new version lands as file.new, and etcnew merges it.

to use another repository, put its address in /etc/jits/repo, or set JITS_REPO for a single command. file:// works too. to find out which package owns a file:

$ grep -lx usr/bin/oksh /var/db/jits/installed/*/manifest

[04] root and users

# jits a yutils
# mkuser foo

foo gets oksh, openbsd's korn shell, and membership of wheel, the group doas lets in. there is no sudo.

$ doas jits u

scripts and the boot run on busybox ash, so anything you write for them has to work there.

[05] wifi

# jits a wpa_supplicant firmware-iwlwifi yutils
# wifi "network" "password"

this connects now and on every boot. realtek cards need firmware-realtek instead. if you do not know which card you have, cat /sys/bus/pci/devices/*/vendor: 0x8086 is intel, 0x10ec is realtek. only wpa2. wpa3 is waiting on you. usb tethering works if the phone is plugged in before boot. none of the firmware has been tested on real hardware. yours would be the first.

[06] desktop

# jits a luwm netsurf wallpaper
$ startw

luwm is the compositor: floating windows, four workspaces, under 180 lines of c on swc. the terminal is havoc. super+return opens it, super+d opens dmenu, super+q closes a window, super+1-4 switches workspace, super+p takes a screenshot.

colours and keys are read from two files, so changing them does not mean recompiling anything:

~/.config/luwm/env
LUWM_BORDER=6
LUWM_FOCUS=3d6fa3
LUWM_UNFOCUS=253e5b

~/.config/luwm/keys
case $1 in
w) exec netsurf ;;
S-x) exec havoc -e yte ;;
esac

setwall sets the wallpaper. only the us keyboard layout, because nobody has added theirs.

[07] packaging

a package is a directory in pkgs/ of yagnilinux/repo:

pkgs/yte/version    0.3
pkgs/yte/source     git https://github.com/yagnilinux/yte.git main
pkgs/yte/build      #!/bin/sh -e
                    musl-gcc -std=c99 -Os -s -static -o yte yte.c
                    install -Dm755 yte "$1/usr/bin/yte"
pkgs/yte/depends    what it needs, one per line, if anything
pkgs/yte/files/     configs and patches, if any

build installs into $1 as if it were /. build static and strip the result. sources are git <url> <tag>, apt-src <pkg> or apt-deb <pkg>. if you change a package, you bump its version. mkrepo refuses to build a changed package under an old version.

[08] building yagni

$ git clone https://github.com/yagnilinux/repo
$ cd repo
$ ./mkrepo      # every package into repo/
$ ./mkrootfs    # yagni.tar.gz
# ./mkiso       # yagni.iso

the build machine needs musl-gcc and lzfse. mkiso also needs root, xorriso and mtools. put repo/ on any web server and point /etc/jits/repo at it. that is all a mirror is.
