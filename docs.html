[01] install

uefi, secure boot off. write yagni.iso to a usb stick and boot it. you land in a root shell. the iso carries everything, no network needed.

# dd if=yagni.iso of=/dev/sdX bs=4M

the kernel finds root by the gpt partition name yagni and by nothing else. name it anything else and it does not boot.

# sfdisk /dev/sda <<EOF
label: gpt
size=256M, type=uefi, name=BOOT
type=linux, name=yagni
EOF
# mkfs.vfat -F 32 -n BOOT /dev/sda1
# mkfs.ext4 -L yagni /dev/sda2
# mount /dev/sda2 /mnt
# mkdir /mnt/boot
# mount /dev/sda1 /mnt/boot

unpack base, set a root password:

# cd /media/install
# sha256sum -c yagni.tar.gz.sha256
# tar xzf yagni.tar.gz -C /mnt
# chroot /mnt passwd

tar complains about permissions on /boot. it is fat. ignore it. wifi only? install it now, see [04]:

# JITS_REPO=file:///media/install/repo jits -r /mnt a wpa_supplicant firmware-iwlwifi yutils
# umount /mnt/boot /mnt
# reboot

stuck at Waiting for root device PARTLABEL=yagni: wrong partition name. sfdisk --part-label /dev/sda 2 yagni. firmware that refuses the fallback path on an internal disk gets an entry from efibootmgr, run from another live system. dual boot: mount your existing efi partition at /mnt/boot and move any EFI/BOOT/BOOTX64.EFI already there out of the way first. yagni writes over it.

[02] boot

the firmware runs /boot/EFI/BOOT/BOOTX64.EFI, and that file is the kernel. its command line is compiled in:

root=PARTLABEL=yagni rootwait rw init=/bin/init firmware_class.path=/share/firmware

busybox init runs /etc/init.d/rcS. that is the entire boot, 32 lines. to start something at boot, add a line. these six files configure the system:

boot/etc/init.d/rcS
consoles/etc/inittab
mounts/etc/fstab
hostname/etc/hostname
who gets root/etc/doas.conf
repository/etc/jits/repo

[03] root and users

# jits a yutils
# mkuser foo

foo gets oksh, openbsd's korn shell, and the wheel group. wheel gets doas.

$ doas jits u

scripts and the boot run on busybox ash. write for ash.

[04] wifi

# jits a wpa_supplicant firmware-iwlwifi yutils
# wifi "network" "password"

connects now and on every boot. realtek cards take firmware-realtek. cat /sys/bus/pci/devices/*/vendor: 0x8086 is intel, 0x10ec is realtek. wpa2 only. wpa3 is waiting on you. usb tethering works if the phone is plugged in before boot.

[05] desktop

# jits a luwm netsurf wallpaper
$ startw

luwm is the compositor: floating windows, four workspaces, under 180 lines of c on swc. the terminal is havoc. super+return opens it, super+d opens dmenu, super+q closes a window, super+1-4 switches workspace, super+p takes a screenshot.

colours and keys live in two files. nothing gets recompiled:

~/.config/luwm/env
LUWM_BORDER=6
LUWM_FOCUS=3d6fa3
LUWM_UNFOCUS=253e5b

~/.config/luwm/keys
case $1 in
w) exec netsurf ;;
S-x) exec havoc yte ;;
esac

setwall sets the wallpaper. us keyboard layout only. nobody has added theirs.
