one program per job. if you want two, package the other one. gnome needs a gigabyte of ram to show you a wallpaper. a whole yagni desktop with a browser open fits in 40MB.

job package
desktop luwm
wallpapers wallpaper
fonts font-kirsch font-imfell font-dejavu
terminal havoc
launcher dmenu
editor yte
files shfm
browser netsurf
system info fastfetch
yagni tools yutils

larger packages:

job package
compiler tcc
version control git
sound alsa-utils
audio and video ffmpeg yt-dlp

whatever tcc builds is static. there is no gcc, make or bash, and there won't be, fuck gnu.

sound starts muted. vol 80 fixes that.

yutils holds yagni's own scripts. none of them are required.

  • mkuser adds a user who can start the desktop
  • wifi saves a network and connects
  • etcnew merges the file.new copies jits leaves in /etc
  • vol sets the volume
  • yt plays a youtube video's audio, or yt -d downloads it. needs ffmpeg and yt-dlp

versions and sizes are on the packages page.

anything else, package it yourself.
