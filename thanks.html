thanks

“If I have seen further, it is by standing on the shoulders of giants.”
  — Isaac Newton

yagni is other people's ideas, stolen with love. these are the ones it owes the most.

kiss linux

writing packages as small build scripts comes from kiss. so is the idea that a package manager can be one shell script you read in a sitting. shfm, the file manager, is by kiss's author too.

github.com/kisslinux

dérive

dérive showed a static musl libc and busybox system can be a whole desktop, not a demo.

derivelinux.org

openbsd

a base that is small, kept apart from the packages and written to be read. when yagni has to choose between a feature and code someone can audit, it asks what openbsd would do.

openbsd.org

exherbo

exherbo keeps the freedom to break things when keeping them costs more, and doesn't try to package the world from the centre. yagni does the same. things get dropped when they cost too much, and jits points at anyone's repository.

exherbo.org
