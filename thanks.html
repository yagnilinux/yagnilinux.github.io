thanks

“If I have seen further, it is by standing on the shoulders of giants.” — Isaac Newton

Most of requiem's ideas come from other projects. These are the ones it owes the most.

sabotage
One of the first distributions built on musl and busybox. The file system without /usr and /sbin, and netbsd-curses, come from it.

KISS Linux
Packages as a few small files and a build script, and a package manager short enough to read in one sitting.

dérive
A static musl and busybox system with a complete desktop.

OpenBSD
A base system that is small, kept apart from the packages and written to be read. doas and ksh come from it.

Exherbo
Breaking things when keeping them costs more, and not trying to package everything centrally.
