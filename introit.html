[01] use

introit [-r root] [a|r|u|s|l] [pkg]...
  a  add       install packages and what they need
  r  remove    remove packages
  u  update    sync the repository, upgrade everything
  s  search    search the repository
  l  list      list installed packages

packages are lzfse tarballs, checked against the sha256 in the index. packages are not signed.

introit removes what you tell it to, including what other packages need. configuration survives upgrades: the new version is written as file.new, and etcnew merges it.

another repository goes in /etc/introit/repo, or in INTROIT_REPO for one command. file:// works. to find the package that owns a file:

$ grep -lx bin/oksh /var/db/introit/installed/*/manifest

[02] packaging

a package is a directory in pkgs/ of requiem/repo:

pkgs/tract/version    0.4
pkgs/tract/source     git https://codeberg.org/requiem-linux/tract.git main
pkgs/tract/build      #!/bin/sh -e
                  musl-cc -std=c99 -Os -s -static -o tract tract.c
                  install -Dm755 tract "$1/bin/tract"
pkgs/tract/depends    what it needs, one per line
pkgs/tract/files/     configuration and patches

build installs into $1 as if it were /. everything is static and stripped. sources are git <url> <tag>, apt-src <pkg> or apt-deb <pkg>. a changed package needs a new version; mkrepo refuses to rebuild it under the old one.

[03] building requiem

$ git clone https://codeberg.org/requiem-linux/repo
$ cd repo
$ ./mkrepo        # every package into repo/
$ ./mkpkg htop    # only htop
$ ./mkrootfs      # requiem.tar.gz
# ./mkiso         # requiem.iso

build on another linux machine; the kernel needs gnu make, which requiem does not ship. the build machine needs clang, lld, compiler-rt and lzfse; cc/musl-cc points clang at a musl built by clang. mkiso needs root, xorriso and mtools. any web server serving repo/ is a mirror.
