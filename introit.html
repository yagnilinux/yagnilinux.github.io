[01] USE

introit [-r root] [a|r|u|s|l] [pkg]...
  a  add
  r  remove
  u  update everything
  s  search
  l  list installed

r doesn't check what else needs it.

new config lands as file.new. etcnew merges it.

packages are checked against the sha256 in the index. nothing is signed.

other repo: /etc/introit/repo, or INTROIT_REPO. file:// works.

$ grep -lx bin/oksh /var/db/introit/installed/*/manifest

[02] PACKAGING

pkgs/tract/version    0.4
pkgs/tract/source     git https://codeberg.org/requiem-linux/tract.git main
pkgs/tract/build      #!/bin/sh -e
                  musl-cc -std=c99 -Os -s -o tract tract.c
                  install -Dm755 tract "$1/bin/tract"
pkgs/tract/depends    one per line
pkgs/tract/files/     config, patches
pkgs/tract/app        makes it an app

build installs into $1. sources: git, apt-src, apt-deb. anything in /usr or /lib fails. changed it? bump the version.

[03] BUILDING REQUIEM

$ git clone https://codeberg.org/requiem-linux/repo
$ cd repo
$ ./mkrepo
$ ./mkpkg htop
$ ./mkrootfs
# ./mkiso

on another linux box with clang, lld, compiler-rt, lzfse and gnu make (the kernel wants it). mkiso needs root, xorriso and mtools. serve repo/ and that's a mirror.
