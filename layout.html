layout

every program on yagni is static, and there is no dynamic loader or shared library anywhere on the system. LD_PRELOAD and LD_LIBRARY_PATH do nothing. glibc binaries don't run, so build yours static or package it.

there is no /lib because there is nothing to load, and no /sbin because root and users run the same programs. /usr is a symlink to / for scripts that start with #!/usr/bin/env.

/bin -> programs
/share -> everything a program reads: data, fonts, firmware, kernel modules, python's library
/etc -> configuration
/boot -> the efi partition, holding the kernel
/var -> logs, and what jits knows in /var/db/jits
/home, /root -> users
/mnt -> whatever you mount
/dev, /proc, /sys, /run, /tmp -> made at boot
/usr -> a symlink to /

musl-dev puts headers and static libraries in /share/include and /share/lib, and tcc links static by default.

mkrepo moves whatever a build puts in usr/bin, usr/sbin or sbin to /bin and usr/share to /share. anything left in /usr or /lib fails the build.
