layout

everything is static: no loader, no shared libraries, no /lib. no /sbin either, root runs what you run. /usr links to / for #!/usr/bin/env. glibc binaries don't run.

/bin -> every program
/share -> data, firmware, modules
/etc -> config
/boot -> the kernel
/var -> logs, jits
/home, /root -> users
/mnt -> mounts
/dev, /proc, /sys, /run, /tmp -> made at boot
/usr -> a symlink to /

headers and .a files: /share/include, /share/lib.

mkrepo fails any package that installs into /usr or /lib.
