layout

every program is static. there is no dynamic loader and no shared library anywhere on the system. LD_PRELOAD and LD_LIBRARY_PATH do nothing. no upgrade can swap a library out from under a program.

a binary built against glibc does not run. it asks for a loader that is not there and dies with not found. build it static or package it.

nothing gets loaded, so there is no /lib. root runs the same programs you do, so there is no /sbin. /usr is a symlink to /, kept for every script that starts with #!/usr/bin/env.

/binevery program
/shareeverything a program reads: data, fonts, firmware, kernel modules, python's library
/etcconfiguration
/bootthe efi partition, holding the kernel
/varlogs, and what jits knows in /var/db/jits
/home, /rootusers
/mntwhatever you mount
/dev, /proc, /sys, /run, /tmpmade at boot
/usra symlink to /

tcc's headers and static libraries go in /share/include and /share/lib with musl-dev. tcc links static by default. there is nothing else to link against.

mkrepo enforces all of it. usr/bin, usr/sbin and sbin get moved to /bin, usr/share to /share. anything else in /usr or /lib fails the build.
