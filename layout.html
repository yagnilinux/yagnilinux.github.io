everything is static. glibc binaries don't run. build it static or package it.

no /lib, nothing gets loaded. no /sbin, root runs the same programs you do.

APPS

one folder each in ~/apps, like macos. no root.

$ introit a netsurf
$ ls ~/apps/netsurf
bin  share  version

move the folder out and it's uninstalled. move it back and it's installed. new apps show up in a new shell.

as root they go in /apps, for everyone.

apps: netsurf, havoc.

THE TREE

/bin -> programs

/share -> everything else

/etc -> config

/boot -> efi partition, the kernel

/var -> logs, /var/db/introit

/home, /root -> users

~/apps, /apps -> apps

/mnt -> mounts

/dev, /proc, /sys, /run, /tmp -> made at boot

/usr -> symlink to /

headers and static libs: /share/include, /share/lib.
